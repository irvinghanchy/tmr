TMR 舞臺時鐘使用與部署指南

🚀 雙視窗簡報操作方式

點擊預覽區旁的「另開展示視窗（簡報模式）」按鈕，即可打開專門給外接螢幕、投影機或 OBS 使用的乾淨時鐘視窗。 後台與展示視窗會透過瀏覽器原生 BroadcastChannel 自動即時同步，操作即點即生效！

🎨 圖示規則與字型規格

  • 字型：採用 Google Roboto Flex，並完整啟用 tabular-nums 等寬數字屬性，數字跳動時絕對平穩不晃動。
  • 目前時間：切換至此模式時，短暫顯示白色 watch，此外不顯示圖示。
  • 正計時：開始/繼續時短暫顯示綠色 timer_arrow_up；暫停時顯示橘色 pause。
  • 倒數計時：開始/繼續時短暫顯示淺藍色 timer_arrow_down；暫停時顯示橘色 pause；響鈴時顯示黃色 notifications_active。
  • 歸零變紅超時：倒數結束到達 00:00 後，時鐘數字立即轉為鮮豔紅色並繼續正數上去。

🌐 部署到 GitHub Pages 或 Vercel

本專案為 100% 純靜態前端架構，無須建置步驟，推送到 GitHub 即可直接上線：

  • GitHub Pages：在 GitHub 倉庫的 Settings ➔ Pages ➔ Source 選擇 Deploy from a branch (main / root)，即可自動發布。
  • Vercel：直接在 Vercel 點擊「Add New Project」並匯入此 GitHub 倉庫，無須任何建置設定即可一鍵部署。
