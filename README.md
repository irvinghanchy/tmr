# TMR 時鐘控制台 | Stage Timer Studio

一個專為大型研討會、演講、競賽、活動舞臺與線上直播（OBS）設計的高質感網頁時鐘與計時器系統。後台採用 **Tailwind CSS + DaisyUI** 現代化介面，純靜態前端架構，可無縫部署於 **GitHub Pages** 或 **Vercel**。

---

## 🌟 核心特色與規格

### 1. 雙視窗簡報與投影模式 (Dual-Window Sync)
- **後台控制台 (`index.html`)**：提供 16:9 實時多圖層淡入淡出預覽、計時控制、快捷增減時間、響鈴警示規則管理與音效設定。
- **展示視窗 (`display.html`)**：點擊「另開展示視窗（簡報模式）」即可獨立開啟。畫面極致純粹，僅呈現時鐘本體與狀態圖示，無任何多餘瀏覽器介面。
- **無延遲雙向同步**：兩視窗透過瀏覽器原生 `BroadcastChannel` 即時同步，操作即點即生效。

### 2. 四大功能圖層與平滑轉場
- **目前時間**：顯示當前系統時間（預設關閉秒數與日期）。
- **正計時**：從 0 開始往上累加計時（分:秒）。
- **倒數計時**：自訂或快捷選擇倒數時間，**歸零（00:00）後立即轉為鮮紅警示色，並自動切換為正計時持續累加超時時間**。
- **黑畫面**：舞臺螢幕瞬間全黑（待命時使用），後台計時器仍維持精準運行。
- **淡入淡出動畫**：後台提供轉場開關與速度調整（0.2s / 0.4s / 0.8s），預覽畫面與展示畫面同步呈現絲滑淡入淡出。

### 3. 字型與數字排版
- **字型**：Google **Roboto Flex** 可變字型。
- **排版參數**：
  - 字重（Weight）：`500`
  - Counter Width（`XTRA` 軸）：`468`
  - 完整啟用等寬數字屬性（`font-variant-numeric: tabular-nums`），數字跳動時絕對平穩不晃動。
- **冒號肉眼幾何對齊**：經過光學垂直微調（`translateY(-0.085em)`），圓點精準置中於時鐘數字幾何中心。
- **冒號瞬閃**：在計時進行中或目前時間模式下，中間的冒號隨秒數俐落閃動（瞬間變化，無多餘漸變）。

### 4. 狀態圖示規格（Material Symbols Rounded）
採用 Google **Material Symbols Rounded**（Not Fill，粗細 450）：
- **目前時間**：切換時，短暫顯示灰色 `watch`。
- **正計時**：開始/繼續或切換至該圖層時短暫顯示綠色 `timer_arrow_up`；暫停時顯示橘色 `timer_pause`。
- **倒數計時**：
  - 開始/繼續或切換至該圖層時短暫顯示淺藍色 `timer_arrow_down`；暫停時顯示橘色 `timer_pause`。
  - 計時中增加時間時，顯示灰色 `more_time`。
  - 計時中減少時間時，顯示灰色 `search_activity`。
  - 觸發預備鈴或結束鈴警示時，顯示黃色微動震鈴 `notifications_active`。
- **多圖示佇列與動態遞補**：
  - 同時出現多個圖示時，側邊模式由上往下排列、下方模式由左至右排列。
  - 上方（左方）圖示消失後，下方（右方）圖示平滑往上（中間）遞補。
- **圖示排版選項**：
  - **側邊顯示（左右平衡）**（預設）：文字尺寸高度為圖示的兩倍，圖示向上對齊；且左側配有等寬平衡間距，確保時鐘數字水平置中。
  - **下方置中（迷你版）**：迷你圖示位於時鐘下方置中，左右無需保留間距。
  - **不顯示圖示**：完全隱藏圖示。

### 5. 控制邏輯與操作體驗
- **開始／暫停互斥切換**：計時中僅出現「暫停」按鈕；暫停時或尚未開始時不顯示暫停按鈕，只顯示開始/繼續按鈕。
- **自動切換圖層**：按下「開始正計時」或「開始倒數」時，自動切換至對應的舞臺顯示圖層。
- **展示中按鈕醒目標示**：目前正在舞臺展示的圖層，其對應的切換按鈕自動呈現 Active 高亮狀態。
- **豐富的微調按鈕**：倒數計時支援 `±5秒`、`±10秒`、`±15秒`、`±30秒`、`±45秒`、`±1分`、`±3分`、`±5分`，以及自訂任意秒數/分鐘的加減時間按鈕。
- **響鈴警示規則**（預設值）：
  1. 剩餘 3 分鐘 ➔ 響 1 聲
  2. 剩餘 1 分半 ➔ 響 2 聲
  3. 剩餘 30 秒 ➔ 響 3 聲
  4. 時間到 (00:00) ➔ 長鳴 3 聲
  5. 超時 30 秒 ➔ 長鳴 3 聲
- **音效合成**：支援普通嗶聲與持續音較長的「長鳴聲」。
- **快捷鍵卡片**：預設收合，保持後台清爽。

## ⌨️ 鍵盤快捷鍵

| 按鍵 | 功能 |
| :--- | :--- |
| <kbd>1</kbd> | 切換舞臺圖層為 **目前時間** |
| <kbd>2</kbd> | 切換舞臺圖層為 **正計時** |
| <kbd>3</kbd> | 切換舞臺圖層為 **倒數計時** |
| <kbd>B</kbd> | 切換 / 解除 **黑畫面 (Blackout)** |
| <kbd>Space</kbd> | **開始 / 暫停** 目前進行中的計時器 |
| <kbd>R</kbd> | **重設** 目前計時器 |
| <kbd>M</kbd> | 鈴聲 **靜音 / 取消靜音** |
| <kbd>F</kbd> | 展示視窗切換 **全螢幕模式** |

## 🚀 部署指南

### 部署到 GitHub Pages
1. 將本專案推送至 GitHub 倉庫（`main` 分支）。
2. 在倉庫的 **Settings** ➔ **Pages** 中，Source 選擇 `Deploy from a branch`（`main` 分支 `/ root` 資料夾）。
3. 儲存後數分鐘即可在 `https://<帳號>.github.io/<倉庫名>/` 啟用。

### 部署到 Vercel
1. 在 Vercel 點選 **Add New Project** 並匯入 GitHub 倉庫。
2. Framework 選擇 **Other**，無須任何建置指令，點擊 **Deploy** 即可。
